# Security policy

This repository contains documentation only. The application it describes runs at [www.oxygencylinderbd.com](https://www.oxygencylinderbd.com/).

## Reporting a vulnerability

If you believe you have found a security issue in the website or in this repository:

1. **Report it privately.** Use the email address on the website's [contact page](https://www.oxygencylinderbd.com/contact-us/), with "Security report" in the subject. Don't open a public issue.
2. **Include** the affected URL or page, the steps to reproduce, what you expected and what happened, and any proof of concept.
3. **Act in good faith.** Don't access, change or delete data that isn't yours. Don't degrade the service, and don't send automated high-volume traffic. Stop testing and report as soon as you have shown the issue.

The team reviews every report and will follow up with you by email.

## Scope

| In scope | Out of scope |
| --- | --- |
| `www.oxygencylinderbd.com` and its public pages and APIs | Denial-of-service or volumetric testing |
| Content of this repository (for example, accidentally published sensitive information) | Social engineering, phishing or physical attacks |
| | Third-party services such as the CDN, Google services and email providers (report those to the vendor) |
| | Automated scanner output without a demonstrated impact |

The design is described in [docs/SECURITY_ARCHITECTURE.md](docs/SECURITY_ARCHITECTURE.md). Internal audit results are not published.
