# Screenshot gallery

> 59 screenshots of the public storefront and the admin panel. [Back to the overview](../README.md)

## How these were captured

| Set | Source | Notes |
| --- | --- | --- |
| Storefront (29) | The live site, `www.oxygencylinderbd.com`, on 26 Nov 2026 | Headless Chrome at 1440 × 900 (desktop) and 390 × 844 at 2× (mobile). Analytics, the visitor beacon and chat requests were blocked, so the captures didn't count as visits. Nothing was submitted; the cart existed only in the browser |
| Admin (30) | A local production build connected to the **development** database | Signed-in staff identities, customer details, chat messages, staff bylines and network names are blurred. Counts and records are development values, not live business data |

Screens that would reveal internal security findings are deliberately not included.
